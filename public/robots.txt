# Правила одни для всех. Робот, для которого есть своя группа, читает только её
# и игнорирует «User-agent: *» (RFC 9309), поэтому поисковые и ИИ-роботы
# перечислены в одной группе с теми же запретами, что и у остальных.
#
# /_next/static открыт намеренно: это CSS и JS, без которых Bing (индекс
# для ChatGPT Search и Copilot) и остальные роботы не могут отрендерить
# страницу. Закрываем только служебные payload-файлы Next, адрес формы заявок
# и служебную 404.
#
# Crawl-delay Google не поддерживает, Яндекс не учитывает с 2018 года —
# скорость обхода задаётся в Вебмастере и Search Console.
#
# Отдельные роботы Яндекса YandexAdditional / YandexAdditionalBot отвечают за
# показ страниц в нейроответах (Поиск с Алисой). Запрет для них убирает сайт
# из нейроответов, не влияя на обычную выдачу, поэтому они разрешены явно.
#
# ИИ-роботы: у каждого вендора роботы разделены по назначению — обучение,
# поисковый индекс и разовая загрузка по запросу пользователя. Разрешаем все
# три вида: цель — максимальная цитируемость.
