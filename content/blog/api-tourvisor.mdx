**Коротко:** API Tourvisor — это платные XML-шлюзы, через которые разработчик получает данные Tourvisor в свою систему: поиск туров по 90+ туроператорам (от 5 000 ₽ в месяц), горящие туры и описания отелей (от 3 000 ₽ в месяц каждый). Доступ выдают после консультации, самостоятельной регистрации нет. Отдельно есть выгрузка заявок с вашего модуля — в XML, JSON или CSV и вебхуком. API нужен, если вы строите свой поиск или приложение; если нужна готовая выдача на сайте — хватит модуля, а для диалога с туристом — ИИ-ассистента.

Запросы «api турвизор» и «api турвизор бесплатно» обычно задают в двух ситуациях: агентство хочет свой красивый поиск на сайте или ищет, как подключить к данным Tourvisor чат-бота. Разберём, что именно продаёт Tourvisor, сколько это стоит, чем API отличается от модуля и выгрузки заявок и когда без разработки можно обойтись.

<Note type="checked">Цены и условия проверены 18 октября 2026 года по официальным страницам Tourvisor. Tourvisor может их менять — перед решением уточните на сайте сервиса.</Note>

## Что такое API Tourvisor

Tourvisor называет свой API **XML-шлюзами**. На официальной странице для агентств их три:

| Шлюз | Что даёт | Цена |
|---|---|---|
| Поиск туров | данные более чем 90 туроператоров с актуальными ценами — для своей поисковой формы или мобильного приложения | от 5 000 ₽/⁠мес |
| Горящие туры | туры, подобранные по снижению стоимости; внешний вид настраиваете сами | от 3 000 ₽/⁠мес |
| Описание отелей | описания отелей и номеров, фото и координаты — там, где они есть | от 3 000 ₽/⁠мес |

Главное отличие от модуля поиска: шлюз отдаёт **данные**, а не готовую форму. Как будет выглядеть поиск, фильтры, карточки туров и бронирование — решает и делает ваш разработчик.

## Есть ли бесплатный API Tourvisor

Бесплатного поискового API у Tourvisor нет: все три шлюза платные, цены — «от», точные условия называют на консультации. Без шлюза и без разработки агентство может получить другое:

- **модуль «Поиск туров» на сайт** — готовая форма и выдача с ценами, входит в тарифы Tourvisor PRO от 2 200 ₽ в месяц (1 590 ₽ при оплате за год), с бесплатным тестом на 10 дней. Как его поставить — в нашей [инструкции по модулю](/blog/modul-tourvisor-na-sayt);
- **выгрузку заявок** с модуля в свою CRM или таблицу — о ней ниже.

## Как получить доступ к API

1. На странице XML-шлюзов Tourvisor оставить заявку на консультацию — имя и телефон.
2. Специалисты Tourvisor связываются, уточняют задачу и условия.
3. После договорённости вы получаете доступ и документацию «XML шлюз TourVisor» — по поиску туров, описаниям и горящим турам.

Самостоятельного подключения, как у модуля, нет. Про тестовый доступ и лимиты запросов на официальной странице не сказано — спрашивайте на консультации.

## Выгрузка заявок и вебхук — это другое

Часто под «API Tourvisor» имеют в виду не поиск, а **экспорт заявок**, которые туристы оставили в модуле на вашем сайте. У Tourvisor для этого есть отдельная техническая документация:

- **обычные заявки** — запрос к `orders.php`, ответ в XML, JSON или CSV; можно забирать порциями и только новые (параметры `limit` и `lastid`);
- **онлайн-заявки** с оплатой — запрос к `ordersonline.php`, в XML или JSON, с данными заказчика, туристов, отеля и перелёта;
- **вебхук** — Tourvisor сам сообщает вашему адресу о новой заявке, а вы забираете её методами выше. Адрес регистрируется через `webhooks.php`.

Ключ `authkey` для выгрузки выдаёт техподдержка Tourvisor. Через выгрузку и вебхук заявки с модуля можно передавать в CRM, у которой нет готовой интеграции с Tourvisor, — например, силами программиста или коннектора.

## Что понадобится, чтобы сделать свой поиск на API

API даёт данные, всё остальное — работа вашей команды:

- **разработчик** — бэкенд, который ходит в шлюз, и интерфейс поиска на сайте или в приложении;
- **справочники** — страны, курорты, города вылета, отели и их описания нужно загружать и обновлять;
- **ожидание результатов** — поиск идёт по десяткам туроператоров одновременно, поэтому интерфейс должен уметь ждать и показывать туры по мере поступления;
- **актуальность цен** — цены и наличие у туроператоров меняются, их нужно проверять перед бронью;
- **бронирование и заявки** — что происходит после выбора тура: форма, оплата, передача менеджеру;
- **поддержка** — доработки при изменениях шлюза и ваших требований.

По рыночным оценкам из нашего [сравнения решений](/sravnenie), разработка на заказ стоит от 130 000 ₽ разово и занимает 2–4 недели, плюс ежемесячная поддержка — и это без стоимости самого шлюза.

## Модуль, свой поиск на API или ИИ-ассистент

| | Модуль Tourvisor | Свой поиск на API | ИИ-ассистент с Tourvisor |
|---|---|---|---|
| Что получаете | готовая форма поиска и выдача на сайте | любой интерфейс и логика, которые сделаете | диалог с туристом 24/7: подбор туров, ответы, заявка менеджеру |
| Нужен программист | нет, вставка кода | да | нет, одна строка кода или бот в MAX |
| Срок запуска | после настройки в кабинете Tourvisor | недели | рабочий день после регистрации |
| Стоимость | тарифы Tourvisor от 2 200 ₽/⁠мес | шлюзы от 5 000 ₽/⁠мес + разработка и поддержка | от 990 ₽/⁠мес, версия «Лид» |
| Отвечает на вопросы туриста | нет | если сделаете | да |
| Доступ к Tourvisor | ваш тариф Tourvisor | ваш договор на шлюз | на стороне сервиса, ключи не нужны |

Эти варианты не исключают друг друга: модуль показывает выдачу тем, кто любит искать сам, а ассистент рядом отвечает тем, кто хочет просто написать «Турция в мае на двоих до 200 тысяч».

## Когда API нужен, а когда нет

**API оправдан**, если вы:

- строите свой сайт-агрегатор или мобильное приложение с собственным поиском;
- хотите нестандартную выдачу — свои фильтры, подборки, логику цен;
- сеть или туроператор с собственной разработкой и планами на годы.

**API не нужен**, если задача — дать туристу поиск на сайте (хватит модуля) или отвечать ему в чате и собирать заявки. Для второго есть [ИИ-ассистент с Tourvisor](/integraciya-tourvisor): версия «Лид» подбирает туры по базе Tourvisor в диалоге, подключение к Tourvisor — на нашей стороне, агентству свои ключи и договор на шлюз не нужны. А если Tourvisor у вас нет совсем, есть [ассистент без Турвизора](/blog/ii-assistent-bez-tourvisor) — он собирает запрос, а тур подбирает менеджер.

## Частые вопросы

### API Tourvisor отдаёт JSON или XML?

Официально продукт называется XML-шлюзом, JSON на его странице не упоминается. Выгрузка заявок поддерживает XML и JSON, обычные заявки — ещё и CSV.

### Сколько туроператоров в API Tourvisor?

Для шлюза «Поиск туров» Tourvisor указывает более 90 туроператоров с актуальными ценами.

### Можно ли подключить данные Tourvisor к чат-боту?

Да, двумя путями: самостоятельно — через XML-шлюз, разработку и свою логику диалога, или готовым ИИ-ассистентом, который уже работает с базой Tourvisor. Во втором случае ни API, ни программист агентству не нужны.

### Нужен ли API, чтобы заявки с модуля попадали в CRM?

С U‑ON, «МоиДокументы-Туризм» и ТурКонтролом у Tourvisor есть готовые интеграции. Для остальных систем подойдут выгрузка заявок и вебхук — ключ для них выдаёт техподдержка Tourvisor.
