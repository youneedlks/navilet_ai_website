## Есть ли у Tourvisor свой ИИ

Короткий ответ — подбора туров с ИИ у Tourvisor нет. С декабря 2025 года Tourvisor показывает в поиске выжимку плюсов и минусов отеля: ИИ собирает её минимум из пяти отзывов за последние полтора года. Бот Tourvisor в MAX и Telegram работает по сценарию: собирает параметры поиска и отдаёт ссылку на результаты, ИИ на его странице не заявлен.

Если нужен живой диалог — турист пишет своими словами, ему отвечают на вопросы о пляже и питании и подбирают варианты, — понадобится ИИ-ассистент поверх данных Tourvisor.

## Как ИИ-ассистент работает с Tourvisor

1. **Понимает запрос.** Турист пишет: «Нужен тур в Египет на двоих в октябре, всё включено, до 180 тысяч». Языковая модель превращает свободную речь в структурированный запрос: страна, даты, ночи, состав, питание, бюджет. Если чего-то не хватает — например, города вылета, — ассистент уточняет.
2. **Ищет через Tourvisor.** Запрос уходит в агрегатор. Поиск в API Tourvisor асинхронный: туроператоры отвечают с разной скоростью — в документации приводится пример, когда один отвечает за 2 секунды, другой за 20. Ассистент показывает варианты по мере ответа.
3. **Показывает карточки.** Отель, звёзды, питание, даты, перелёт и цена на момент запроса.
4. **Консультирует.** Отвечает на вопросы о пляже, питании, перелёте и визах — по базе знаний агентства.
5. **Собирает подборку.** Выбранные варианты попадают в [подборку по ссылке](/podborki) — страницу под брендом агентства с фото отелей, вкладкой «Перелёт» и кнопкой «Обновить цены». Клиент пересылает её близким, агентство видит открытия.
6. **Передаёт заявку.** Контакт и весь диалог уходят менеджеру — на почту, в U‑ON, [в Telegram или MAX](/blog/uvedomleniya-o-zayavkah-telegram-max).

Подключение к Tourvisor — на стороне «Навылет! AI»: агентству не нужны свои ключи и договор на API.

## Почему нет выдуманных цен

Языковая модель отвечает за понимание и формулировки, а за факты — агрегатор. Ассистент не придумывает цену: он показывает то, что вернул Tourvisor в момент запроса. Такой подход называют RAG — генерация с опорой на внешние данные. Он убирает главный риск ИИ: уверенные, но неверные ответы.

Цены туров меняются быстро. Результаты поиска в API Tourvisor живут не больше 20 минут, поэтому ассистент называет цену на момент запроса, а в подборке есть кнопка «Обновить цены». Окончательную цену и наличие при бронировании подтверждает туроператор.

> Модель отвечает за разговор. База отвечает за цифры.

## Что ассистент не делает

- **Не бронирует и не принимает оплату.** Бронь оформляет менеджер — ассистент передаёт ему клиента с готовым запросом.
- **Не обещает того, чего нет в базе.** Если подходящих туров в базе нет, ассистент их не придумывает.
- **Не заменяет менеджера на сложных маршрутах.** Комбинированные туры, группы, особые условия — работа человека.

## Своя разработка на API или готовый ассистент

Сделать своего бота на данных Tourvisor можно. Понадобятся доступ к API (поиск — от 5 000 ₽ в месяц), программист, языковая модель, логика диалога, передача заявок и поддержка. Это месяцы работы и отдельный бюджет. Готовый ассистент подключается за день, с подбором туров стоит от 990 ₽ в месяц, а первый месяц бесплатный. Разница в цене и сроках — в разборе [API Tourvisor](/blog/api-tourvisor).

Если у агентства нет Tourvisor или тур подбирают менеджеры, подойдёт версия «Заявка» от 790 ₽ в месяц: ассистент собирает запрос и контакт, а подбор остаётся за менеджером. Подробно — в статье [про ИИ-ассистента без Турвизора](/blog/ii-assistent-bez-tourvisor).

## Частые вопросы

### Нужен ли агентству свой договор на API Tourvisor?

Для ИИ-ассистента «Навылет! AI» — нет: подключение к Tourvisor на стороне сервиса. Свой доступ к API нужен, только если вы делаете собственную разработку.

### Есть ли у Tourvisor свой ИИ-модуль подбора туров?

Нет. ИИ у Tourvisor — в выжимке отзывов об отелях, бот работает по сценарию без ИИ. Живой диалог с подбором даёт ИИ-ассистент, подключённый к данным Tourvisor.

### Насколько актуальны цены, которые называет ассистент?

Это цены на момент запроса из базы Tourvisor. Окончательную цену при бронировании подтверждает туроператор; в подборке по ссылке цены можно обновить кнопкой.

### Можно ли поставить ассистента рядом с модулем поиска Tourvisor?

Да. Модуль остаётся для тех, кто ищет сам, а ассистент ведёт диалог с теми, кому нужна помощь. Как это сделать — в инструкции [«Модуль Tourvisor на сайт»](/blog/modul-tourvisor-na-sayt).

### В каком формате API Tourvisor отдаёт данные?

У Tourvisor есть JSON API для поиска туров (в документации — версия 1.2.6, авторизация по токену из кабинета агента) и XML-шлюзы. Подробности — в статье [API Tourvisor](/blog/api-tourvisor).

### Сколько стоит своя разработка на API?

Только доступ к поиску — от 5 000 ₽ в месяц. Сверху — разработка, языковая модель и поддержка. Готовый ассистент с подбором туров — от 990 ₽ в месяц.
